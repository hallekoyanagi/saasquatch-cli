# SaaSquatch CLI

A small Java command-line app for a co-op application.

## Run

**Compile:**

```bash
javac -cp "lib/picocli-4.7.7.jar" SaasquatchCli.java
```

**Run:**

Windows

```bash
java -cp ".;lib/picocli-4.7.7.jar" SaasquatchCli
```

Linux/Mac

```bash
java -cp ".:lib/picocli-4.7.7.jar" SaasquatchCli
```
